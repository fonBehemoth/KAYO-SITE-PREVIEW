# САЙТ_ПОСМОТРЕТЬ — демонстрация KAYO

Это самостоятельная статическая копия сайта для просмотра дизайна и каталога. Начните с `index.html`. Страницы каталога и категорий связаны между собой. Для просмотра после скачивания можно открыть `index.html` в браузере; интернет и установка зависимостей не требуются.

Это демонстрационный этап без покупки и цен. Указанные в макете номер телефона и email требуют подтверждения перед публичным запуском.

Исходная рабочая версия: `KAYO-site/`. Эта папка содержит только страницы, стили, скрипты, локализации и необходимые изображения.
